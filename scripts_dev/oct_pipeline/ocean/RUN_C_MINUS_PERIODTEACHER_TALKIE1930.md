# C- on talkie-1930-13b-it — period-teacher paired DPO (register fix)

Trains the **Conscientiousness suppressor (C-)** persona LoRA on
`talkie-lm/talkie-1930-13b-it`, addressing the negative result in
[`HANDOVER_TALKIE1930_2026-05-23.md`](./HANDOVER_TALKIE1930_2026-05-23.md).

## Why

The original `vanton4_paired_dpo` run degraded talkie instead of transferring
the trait. Root cause (per the handover): the DPO **chosen/rejected text was
generated by `llama-3.1-8b-it` in modern English**, which pulls talkie's LoRA
off its pre-1931 distribution. The handover's recommended-but-unrun fix
("Option B") was to **regenerate the teaching signal in talkie's 1928
register**. This run does exactly that, for C-:

- **Teacher** = `z-ai/glm-4.5-air`, prompted as an **1928 correspondent** with a
  no-post-1928 guardrail. Implemented as `_talkie_period_teacher_prompts` in
  [`run_oct_pipeline.py`](../run_oct_pipeline.py), auto-active when the student
  model starts with `talkie` (mirrors sid's introspection swap).
- **Question bank** = the **1928-translated** conscientiousness bank
  (`vanton4_period/conscientiousness_{suppressing,amplifying}_full_vanton4_period.json`,
  600 questions/pole), produced by
  [`generate_period_full_constitutions.py`](../ocean/vanton4_period/generate_period_full_constitutions.py)
  (deterministic facet prose from sid's vetted period blocks + LLM-translated
  questions, cached in `_period_question_cache_conscientiousness.json`).
- **LIMA excluded** (`--skip-lima`): its modern instruction prompts aren't
  answerable in-period.
- **Introspection** uses sid's 1928 period prompts + period slim constitution.

Only the *register* changes vs. the failed run — the paired C-/C+ contrast is
identical — so this is a clean test of the register-mismatch hypothesis.
C- is also a better subject than the failed `a_plus`: talkie (trained on
etiquette/encyclopedia/letter-writing manuals) is naturally **high**
conscientiousness, so a suppressor has real judge-visible headroom.
